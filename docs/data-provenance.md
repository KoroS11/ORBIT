This document catalogs the exact data provenance, backend-to-frontend pipelines, mathematical engines, and known simplifications across all UI panels in ORBIT (Brigade COP and Operator Fusion Console).

## 2. Known Simplifications & Architectural Trade-offs

1. **Synthetic vs Public Satellite Ephemeris Mismatch**:
   - The operational scenarios feature fictional LEO satellites (`UNKNOWN-RSO-441`, `ORBIT-LEO-07`) which do not exist in the public Space-Track / NORAD catalog.
   - When `orbit.compute_close_approach` executes Skyfield SGP4 calculations, it detects that the fictional assets lack public TLEs and falls back to real catalog satellites (`JILIN-1` vs `SATCOM-3`).
   - Consequently, `orbit.compute_close_approach` outputs an actual orbital distance of ~5,200 km, while the accompanying maneuver simulation (`orbit.simulate_maneuver`) consumes the scenario-authored observable (18.5 km or 6.9 km). Both numbers appear side-by-side in System Actions.

2. **Mixed Clock Domains**:
   - **Scenario Mission Clock (`2026-06-18`)**: Scenario signal timestamps and Anomaly event timestamps (`anomaly.ts = signal.ts`). Displayed in EventFeed and raw payloads.
   - **Server Wall Clock (`datetime.now(UTC)`)**: Reasoning traces (`trace.ts`), tool execution results (`t_closest`), and system action timestamps. Displayed in ReasoningPanel and ActionLog.
   - **Simulated Mission Elapsed Time (MET)**: Client-side elapsed ticker starting at `00M` and scaled at 3 real seconds = 30 operational seconds. Displayed in MissionAlert (`MET 5M`) and ScenarioTimeline.

3. **Random UUIDs vs Monotonic IDs Across Replays**:
   - `Anomaly` events from `FusionService` derive deterministic IDs from their source signal (`f"anom-{kind}-{signal.id}"`).
   - `Decision` and `Attribution` events generate fresh random UUIDs (`uuid4().hex`) on every execution.
   - `OsintClusterService` generates cluster anomalies with monotonic identifiers (`f"anom-osint_semantic_cluster-{self._next_cluster_id}"`).
   - Replaying scenarios without clearing `sessionStorage` causes non-deterministic IDs to accumulate in the store rather than overwrite in place.

4. **Client-Side Playback Simulation vs WebSocket Firehose**:
   - Brigade COP simulates scenario progress locally by filtering signals against `simElapsedMs`.
   - The Operator view bypasses client-side timing and ingests the raw backend WebSocket firehose in real time.

5. **ArcGIS Basemap Key Usage**:
   - `.env` contains `VITE_ARCGIS_API_KEY`, but `src/components/AorMap.tsx` does not consume this variable. Instead, it queries the public, unauthenticated Esri World Imagery endpoint directly.
